# MathKing Class Landing Page

## 환경변수 설정

프로젝트 루트에 `.env` 파일을 생성하고 다음 환경변수를 설정하세요:

```bash
# 무료체험 신청 API URL (선택사항 - 기본값 사용 시 생략 가능)
REACT_APP_CONSULTATION_API_URL=https://api-prod.iammathking.com/api/v3/organization/business_request
```

## 개발 서버 실행

```bash
npm start
```

## 빌드

```bash
npm run build
```
